# Manifesto (condensed canonical)

The full original is preserved at
`library/originals/MANIFESTO-persistent-cognitive-ecology.md` — this is the
working condensation the codebase is built against.

**The organism question:** what are the minimum conditions under which a
computational ecosystem becomes more useful through continued existence?
Intelligence is the accumulation of effective organization through time.

**The Four Laws** (each mapped to code in `docs/ARCHITECTURE.md`):

1. Time is the substrate — the world exists before the player logs in.
2. Attention is the scarce resource — the system is an economy, not a hierarchy.
3. Why precedes memory — every asset justifies itself or becomes questionable.
4. LLMs are teachers — the runtime must mostly work without them.

**The stack:** L0 runtime · L1 event fabric · L2 world state graph ·
L3 simulated futures · L4 script ecology · L5 agent organisms · L6 WHY ·
L7 sleep — with an attention economy, a tension field, and identity as a
stable attractor running through all of it.

**The core question, executable:** what is the smallest persistent world
that can improve itself while nobody is watching? (`ecology week`)

**The measurement:** accumulated capability, retained usefulness,
adaptation rate, surprise generation, successful specialization,
justification efficiency. Success is more *leverage* — exploratory
bandwidth — not more automation.

**The final question:** after ten years of models coming and going, what is
the smallest structure that must remain true for the organism to still be
itself? Find that. Everything else is implementation.
